BABURAM MISHTAN BHANDAR - WEBSITE
===================================

Files:
- index.html  -> Complete website
- README.txt  -> This guide

HOW TO USE IN ACODE
-------------------
1. Extract the ZIP.
2. Open the extracted folder in Acode.
3. Open index.html.
4. Tap Preview.
5. The website needs internet access because the fonts and photos are loaded online.

IMPORTANT
---------
- The website uses square 1:1 image blocks.
- Replace the sample image URLs with the shop's real photos for the final website.
- Check the phone number, address, opening hours and other business information before publishing.
- The Google Maps button uses the Maps link supplied for the business.

NO BACKEND
----------
This is a frontend-only HTML website. No Firebase, database or server is required.

EDITING
-------
You can edit the text, images, colours and contact information directly inside index.html.
